FridayLang Scripting Language

A serious self-made C++17 project: a lightweight, high-performance scripting language with unified STL-like containers and mathematical algorithm scopes.

Project Overview

FridayLang is a lightweight, dynamically typed scripting language built in C++17 from the ground up. To avoid external libraries, the core compiler contains a handwritten lexer, recursive descent parser, and runtime scope tree. It features C++ standard-like data containers, first-class functions, and object-oriented paradigms.

Syntax Showcase

// Defining a Class in FridayLang
class Warrior {
    init(name, power) {
        this.name = name;
        this.power = power;
    }
    attack() {
        speak "Arthur attacks for " + this.power;
    }
}

// Initializing and invoking methods
take hero = Warrior("Arthur", 15);
hero.attack();
