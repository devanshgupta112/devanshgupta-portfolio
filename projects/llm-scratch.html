127M LLM From Scratch

A deep engineering showcase: compiling, tokenizing, and training a 127 million parameter Large Language Model from raw text to conversational chatbot.

Project Overview

Rather than utilizing pre-trained networks via APIs, this project was built to understand the mathematical mechanics and software systems supporting generative models. The model was trained from scratch—converting raw textual files into structured token vocabularies and running custom backpropagation loops in PyTorch.

This workflow successfully scaled from an empty directory to a query-responsive chatbot agent capable of contextual message completion and formatting logic.

Custom BPE Tokenizer

Standard GPT tokenizers rely heavily on pre-compiled libraries. To avoid these black-box dependencies, I wrote a custom Byte Pair Encoding (BPE) tokenizer from scratch:

The tokenizer scans bytes of raw training documents, calculates token frequencies, and builds a merge vocabulary map recursively. It handles out-of-vocabulary bytes cleanly, preventing model crashes during raw inference loops. 

def get_stats(ids):
    counts = {}
    for pair in zip(ids, ids[1:]):
        counts[pair] = counts.get(pair, 0) + 1
    return counts

def merge(ids, pair, idx):
    newids = []
    i = 0
    while i < len(ids):
        if i < len(ids) - 1 and ids[i] == pair[0] and ids[i+1] == pair[1]:
            newids.append(idx)
            i += 2
        else:
            newids.append(ids[i])
            i += 1
    return newids
