Weather Data Analysis

A Python-powered data science dashboard analyzing 3 years of meteorological datasets to yield visual insights and trend predictions.

Project Overview

This analytics dashboard processes historical climate distributions, temperature fluctuations, and precipitation correlations. Leveraging Python's scientific ecosystem, the pipeline loads, cleans, and structures messy csv files to run exploratory data analysis (EDA).

The visual dashboard helps identify macro weather cycles, anomalous temperature deviations, and regional air pressure trends through clean interactive chart sheets.

Mathematical & Statistical Processing

Data cleaning structures missing indices and eliminates statistical outliers via standard deviations. The metrics engine calculates rolling averages, temperature gradients, and correlation matrices between humidity levels and air pressures. 

import pandas as pd
import numpy as np

# Load and handle missing data
df = pd.read_csv("weather_raw.csv")
df["temperature"] = df["temperature"].interpolate(method="linear")

# Calculate rolling averages & anomalies
df["temp_rolling_mean"] = df["temperature"].rolling(window=7).mean()
anomaly_threshold = 3 * df["temperature"].std()
anomalies = df[np.abs(df["temperature"] - df["temperature"].mean()) > anomaly_threshold]
